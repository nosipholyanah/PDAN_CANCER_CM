# Cancer Tumour Classification: Supporting Dread Disease Benefit Decisions

A classification project that predicts whether a tumour is **benign or malignant** from image-based measurements, built as a basic analysis for a medical scheme that wants to speed up how it applies dread disease benefits for cancer.

## Project Overview

The medical scheme wants to identify customers with a malignant tumour more quickly so that qualifying customers receive their benefits sooner. This project cleans and explores a cancer dataset, trains a logistic regression classifier, and evaluates it with a focus on **malignant recall**, because a missed malignant case could mean a customer is overlooked or their benefit is delayed.

## Dataset

- **Breast Cancer Wisconsin (Diagnostic)** dataset ([Kaggle](https://www.kaggle.com/datasets/uciml/breast-cancer-wisconsin-data) / UCI Machine Learning Repository)
- 569 records, 30 numerical tumour measurements (radius, texture, perimeter, area, smoothness, compactness, concavity, concave points, symmetry and fractal dimension, each as a mean, standard error and worst value)
- 357 benign (62.7%) and 212 malignant (37.3%)
- To run the notebook, download the data from the link above and save it as `data.csv` in the same folder as the notebook.
